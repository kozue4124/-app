# 自動字幕生成ツール

音声・動画ファイルから字幕を自動で作成するツールです。

---

## 使い方

### 1. ツールを起動する

| OS | やること |
|----|---------|
| Mac | `字幕生成ツール起動.command` をダブルクリック |
| Windows | `字幕生成ツール起動.bat` をダブルクリック |

> 初回だけ数分かかります。2回目以降はすぐ起動します。

ブラウザが自動で開きます。

---

### 2. ファイルをアップロードする

ブラウザの画面に音声・動画ファイルをドラッグ＆ドロップします。

対応形式: MP3 / WAV / MP4 / MOV / AVI など

---

### 3. 設定を選ぶ

| 設定 | 選ぶもの |
|------|---------|
| モデル | `small（バランス良好）` がおすすめ |
| 言語 | 日本語の動画なら `日本語` を選ぶ |
| 出力形式 | 動画編集ソフトで使う場合は `srt` |

---

### 4. 「字幕を生成する」をクリック

しばらく待つと字幕ファイルがダウンロードできます。

---

### ツールの終了

ブラウザを閉じて、起動時に開いたウィンドウ（黒い画面）も閉じてください。

---

### うまくいかないときは

| 症状 | 対処 |
|------|------|
| 起動が遅い | 初回は数分かかります。そのまま待ってください |
| 精度が低い | モデルを `medium` や `large` に変更してください |
| 文字化けする | 言語を「日本語」に手動で指定してください |
